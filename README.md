# Zhan Rui



Graduate Student in Information Systems Management at City University of Hong Kong.



I build **evidence-first, change-aware AI agents** for decisions that must remain trustworthy when their supporting information changes.



## Featured projects



### [TracePilot ChangeGuard](https://github.com/zhan-rui/tracepilot-changeguard)



A local-first evidence tool for dependency-upgrade and security-review decisions. It compares previous and current trusted source packs, maps each claim to exact evidence with content hashes, and reopens a conclusion when changed evidence makes it unsafe to reuse.



**What it demonstrates:** provenance, paragraph-level change detection, bounded state transitions, safe abstention, Markdown / JSON Decision Packets, deterministic tests and CI. The default workflow makes **zero network calls and zero LLM calls**.



[Explore the repository →](https://github.com/zhan-rui/tracepilot-changeguard)



### [Career Evidence Guard](https://github.com/zhan-rui/career-evidence-guard)



A local-first evidence agent for job seekers. It tracks job-posting changes and shows which assumptions about requirements, location, deadlines or work arrangements should be checked again.



**What it demonstrates:** AI product problem framing, evidence alignment, low-cost local workflows, human review and reproducible evaluation.



[Explore the repository →](https://github.com/zhan-rui/career-evidence-guard)
